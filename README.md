# 👟 Shoes Store App

A modern **Shoes Shopping Mobile Application** built using **Flutter**.
The app provides a seamless shopping experience where users can browse shoes, view product details, add items to the cart, make secure payments, and track their order history.

The application also supports **Dark Mode and Light Mode**, ensuring a comfortable user experience in different environments.

---

## 📱 Features

* 🛍️ Browse a wide variety of shoes
* 🔎 View detailed product information
* 🛒 Add and remove products from cart
* ❤️ Add items to favorites
* 🌙 Dark Mode & ☀️ Light Mode support
* 🔄 State management using **Provider**
* 🔐 Firebase backend integration
* 💳 Secure **Payment Gateway Integration**
* 📦 **Order History** to track previous purchases
* ⚡ Smooth and responsive UI
* 📱 Optimized for Android devices

---

---

## 🔥 Firebase Services Used

* **Firebase Authentication** – User login and signup
* **Cloud Firestore** – Store products, cart data, and order history
* **Firebase Storage** – Store product images

---

## 💳 Payment Integration

The application integrates a **secure payment gateway** that allows users to complete their purchases safely.
Users can review their cart items, proceed to checkout, and complete payments within the app.

---

## 📦 Order History

Users can easily view their **previous orders**, including:

* Purchased products
* Order date
* Payment status
* Total order amount

This allows users to track and review their purchase history anytime.
